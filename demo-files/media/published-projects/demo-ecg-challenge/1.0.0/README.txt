Predicting Acute Hypotensive Episodes: demo files

sample-entry.tar.gz is a ready-to-upload baseline submission. Download it and
upload it unchanged through the challenge submission page. It contains the
source code and instructions for trying or modifying the entry locally.

training-data/ contains two small synthetic patient records and their labels.
These files illustrate the input format; they are not the full challenge data.
To try the entry locally, extract the archive, then run main.py with INPUT_DIR
pointing to training-data/ and OUTPUT_DIR pointing to an empty directory.

Validation and test records, their labels, and the scoring script are stored
privately for the evaluation service. They are not included in this download.
