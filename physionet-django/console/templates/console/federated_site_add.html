Configuration Guide
  • Name: A unique identifier (lowercase, no spaces). Example: healthdatanexus
  • Display Name: The human-readable name shown in search results. Example: Health Data Nexus
  • Base URL: The root URL of the external site. Example: https://healthdatanexus.ca
  • API Endpoint: The search API path (usually /api/v1/projects/search/ for PhysioNet clones)
  • Site Type: Select PhysioNet Instance for PhysioNet clones
  • Auth Token: Optional. Only needed if the external API requires authentication
  • Order: Lower numbers appear first in search results (e.g., 0 = highest priority)
