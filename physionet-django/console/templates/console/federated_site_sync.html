About Background Sync

Clicking "Queue Sync Task" will schedule a background task:

  • The task is queued immediately and the page returns right away
  • A background worker process picks up and executes the task
  • New projects will be added to the local cache
  • Existing projects will be updated with latest metadata
  • Projects no longer on the remote site will be marked as stale
  • Refresh the detail page after a minute to see results in sync logs
Background Worker Required

Important: The background worker must be running for tasks to execute.
Run in a separate terminal: python manage.py process_tasks
For production, use a process manager like supervisor or systemd.
