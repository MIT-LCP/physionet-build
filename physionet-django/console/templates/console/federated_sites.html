About Federated Sites

Federated sites allow multiple PhysioNet instances to share project metadata for unified search. Each site periodically syncs metadata from registered peers via their REST API.

  • Active: Sites marked as active will be included in automatic sync jobs
  • Sync Status: Shows the result of the most recent synchronization attempt
  • Cached Projects: Number of projects cached locally from this site

To manually sync a site, click the icon or run: python manage.py sync_federated_sites --site <identifier>
