Seeing “Invalid verification code (incorrect signature)”?

This can happen when your AWS account blocks signed S3 requests. To check, run these commands using the same AWS credentials you used for verification: 

aws s3 ls s3://physionet-open/
aws s3 ls s3://physionet-open/ --no-sign-request

If the first command returns AccessDenied and the second one works, signed requests may be blocked by your account's permissions or organization policies. Accounts created through the “Sign up for AWS (new)” flow can be subject to organization policies managed by AWS that restrict S3 access. If this applies to your account, you may consider creating a new AWS account through the “Sign up for AWS (advanced)” flow. Please review the differences between the sign-up options in the AWS documentation.

Once the first command works, generate a new verification command on the verification page, run it exactly as shown, and submit the complete output (the full URL, without line breaks) again.
