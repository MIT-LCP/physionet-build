{# Lets authors ask the editors for a private link for journal reviewers #}
Reviewer Access

If a manuscript that describes this project is under review at a journal, the editors can create a private link and passphrase so that the journal's reviewers can see the project before it is published.

Reviewers see the project as it currently appears to the editors. Any changes made during the {{ SITE_NAME }} review will also be visible to them. Links stay valid for up to 180 days, but stop working immediately if the project is rejected, archived or deleted. Once the project is published, the link also stops working and reviewers should use the published project page instead.

Providing a reviewer link is not a decision on the submission, and there is no guarantee that the project will be accepted.
